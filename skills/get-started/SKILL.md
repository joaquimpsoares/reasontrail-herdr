# Using ReasonTrail

- Use the current project context before relying on old conversation details.
- Check current approved decisions when the user asks what was decided. Mark pending proposals as pending.
- Search only the selected project's authorized records, conversations, and Resources. Explain when a source index is not covered.
- Treat captured decisions and tasks as proposals unless ReasonTrail returns canonical approved records.
- Do not try to bypass ReasonTrail's review process or use tools outside the OAuth-granted scopes.
- The connected AI client chooses and pays for its own model. ReasonTrail provides project context and governed memory workflows.
